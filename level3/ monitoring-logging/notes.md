# Level 3 – Task 5: Monitoring & Logging

## Step 1: Monitor Resources
docker stats

## Step 2: View Logs
docker logs <container_id>

## Step 3: Centralized Logging
- Use ELK/EFK stack
- Forward container logs with Fluentd or Filebeat

## Step 4: Metrics Collection
- Integrate Prometheus with cAdvisor
- Visualize with Grafana

## Step 5: Alerts
- Configure Prometheus alert rules
- Send notifications via email/Slack
